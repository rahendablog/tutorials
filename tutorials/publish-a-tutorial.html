How to publish a new tutorial on this site

Add a one-page tutorial like this one, straight from the GitHub website. You won't need to install anything.

  • ⏱ 15 min
  • 🎯 No technical skills needed
  • 🗓 Updated September 2026

What you'll be able to do

  • Create a tutorial pageStart from a template that already has the layout, progress bar and dark mode.
  • Fill it inReplace the yellow placeholders with your own steps.
  • Publish itMake it appear on the home page for everyone.

Before you start

Check that you have these before you begin:

1

Copy the template

The template already contains every section a good tutorial needs.

  1. Open the repository on GitHub and go into the tutorials folder.
  2. Open _template.html, then click the Copy raw file icon.
  3. Go back to the folder, click Add file → Create new file.
  4. Name it with lowercase words and dashes, for example set-up-alerts.html, and paste the template.
Tip

The file name becomes part of the web address, so keep it short and descriptive.

You should now see

A new file in the editor, full of placeholders in square brackets.

2

Write your content

Placeholders show up in yellow, so nothing unfinished slips through.

  1. Replace every text in [square brackets] with your own words.
  2. Once a placeholder is filled in, remove the <span class="fill"> around it.
  3. To add a step, copy a whole <section class="step"> block, give it the next number, and add a matching link in the table of contents.
  4. Delete the yellow banner at the top of the page.
  5. Click Commit changes.
Watch out

Each step's id (like step-3) must match its checkbox data-step and its table-of-contents link. Otherwise the progress bar won't count it.

You should now see

Your file saved in the tutorials folder.

3

List it on the home page

Readers find tutorials from the home page, so yours needs a card there.

  1. Open index.html at the root of the repository and click the pencil icon.
  2. Find the list that starts with <ul class="tutorial-grid".
  3. Copy one <li> card, then change its link, tag, title, summary and duration.
  4. Click Commit changes.
You should now see

A new card in the code, pointing to tutorials/your-file.html.

4

Check it live

GitHub rebuilds the site after each commit. It usually takes about a minute.

  1. Open the Actions tab and wait for the latest run to show a green check.
  2. Open the site and refresh the home page.
  3. Click your card and read the tutorial once from top to bottom, on your phone too.
You're done

Your tutorial is live. Share the link, and update the “Updated” date whenever you change it.

Troubleshooting

Something doesn't look right? Find what you see below.

The page shows no colours or layout
The stylesheet link is broken. Make sure the file is directly inside the tutorials folder and still has href="../assets/css/theme.css".
I get a 404 “page not found”
Wait a minute for the build to finish, then check the web address matches the file name exactly, including .html.
A step doesn't count in the progress bar
Its checkbox is missing data-step, or the value doesn't match the step's id.

Glossary

Words you'll see on GitHub, explained simply.

Repository
The project folder on GitHub that holds every file of this site.
Commit
Saving a change, with a short note on what you changed.
GitHub Pages
The free GitHub service that turns the repository into a website.
